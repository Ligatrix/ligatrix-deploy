# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Email **info@ligatrix.com** with "Security" in the subject. Please do not open a public issue.

Include:

- the file and setting affected (for example `nginx/snippets/security-headers.conf`);
- what an attacker could do, and under which deployment conditions;
- steps or a configuration that reproduces it;
- the version or commit you tested.

We acknowledge every report within 2 business days, tell you whether we accept it, and keep you informed until a
fix is released. We credit reporters in the changelog unless you ask us not to.
